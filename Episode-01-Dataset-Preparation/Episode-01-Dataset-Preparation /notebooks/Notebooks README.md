# Dataset Exploration Notebook

## Overview
This notebook contains practical experiments related to dataset preparation for the Jabarti LLM from Scratch learning series.

## Objectives
- Explore dataset structure and columns.
- Check for missing values.
- Inspect duplicate text records.
- Analyze language distribution.
- Examine text length and estimate token counts.
- Explore context window requirements.

## Notebook
`01_dataset_exploration.ipynb`

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Install any required libraries.
3. Configure the dataset path and load the dataset.
4. Run the notebook cells in order.
